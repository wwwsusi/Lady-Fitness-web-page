# Lady Fitness repository instructions

Read [website governance](docs/00_WEBSITE_GOVERNANCE.md) before changing website content or assets.

This repository is implementation truth. Google Drive is business truth; 03_PROJECT_INSTRUCTIONS.md there is the highest project governance document. These instructions apply that governance and do not replace it.

- Use approved Drive requirements; preserve unknown facts as TBD and existing product lifecycle distinctions.
- Never treat README history, code, commits or deployed copy as authority to change business facts.
- Do not mirror the private business KB or original photo archive into this public repository.
- Use DECIDE → RECORD → IMPACT CHECK → IMPLEMENT → TEST → MERGE → VERIFY.
- Work in a branch/PR and record the canonical source, scope and validation. Do not merge or deploy without authorization.
- When required business sources cannot be read, record the gap and leave dependent changes pending; continue useful independent work.
- Preserve unrelated code and assets. Documentation-only changes require content/diff checks; application changes require relevant checks from package scripts and the actual environment.
